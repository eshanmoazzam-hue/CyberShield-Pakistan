
# CyberShield Pakistan

## Project Description
CyberShield Pakistan is a Java-based web application
designed to help individuals report common cyber
incidents and access verified cybersecurity awareness
information.

## Objectives
- Provide a structured cyber incident reporting platform.
- Allow moderators to review submitted reports.
- Share anonymised cybersecurity alerts.
- Promote safe digital practices in Pakistan.

## Technologies
- Java 21
- Spring Boot
- Spring MVC and Thymeleaf
- PostgreSQL
- Spring Data JPA
- Spring Security
- Bootstrap 5
- Maven

## Main Users
1. Reporter
2. Moderator
3. Public Visitor
